## Original problem

The P1-v8.4-A four-factor realization became functionally redundant during training. Historical fresh baseline residual functional rank moved approximately `1.06 → 1.65 → 1.52`; normal patches were dominated by F1 while anomaly regions historically carried useful F2/F3/F4 behavior. The completed necessity autopsy found that Full4 did not prove four-factor necessity, and M2 was reviewed but not scientifically justified (`M2_NOT_JUSTIFIED_AFTER_VERIFICATION`).

## Root-cause investigation completed

- **H1 — region/normal dominance:** tested and partially supported as a data/gradient asymmetry, not established as the sole architectural cause. The fixed causal probe had 43,977 normal versus 69 anomaly patches; production factor-gradient vector norm was 96.15% anomaly and 3.85% normal. The asymmetry is real, but does not by itself explain trained F2/F3/F4 residual redundancy.
- **H2 — q-factor responsibility softness:** tested and rejected as a mechanism. `h2_zero_step_proof.json` shows the standardized target preserved all non-factor outputs, winners, state, and invariants; q entropy changed only by `-0.0053261` and max probability by `+0.0059904`. The H2 branch was correctly not taken to 8B/300B.
- **H3 — late factor identity/shared-generator bottleneck:** tested and insufficient. `h3_zero_step_proof.json` used scale `0.02` and max ratio `0.05`; the tangent/cap invariants passed and factor identity received gradient, but dynamic-text rank changed by `-0.0000206` and true-residual rank by only `+0.0143784`. It was a bounded trainable but cosmetic offset, not a validated rescue.
- **True-residual functional specialization:** tested through zero-step, 8B, 300B, and a fresh continuous 3e. The loss operated on `factor_residual_logits`, not absolute factor patch logits; calibrated `lambda_func = 1.0012450025048378e-07` with the P95 safety cap active. Operational gates passed, but the subsequent E3 architecture audit still found redundancy.
- **Primary-anchored surgery:** tested as a frozen control/invariant-preserving mechanism. It did not produce evidence that the trained residual functions became necessary; no surgery, Router, ACT, rho, or factor-loss science change was combined with the latest generator intervention.
- **Router behavior:** audited, not repaired. Earlier E3 evidence showed anomaly teacher/dense top-1 agreement about `5.04%`, but Router remediation was explicitly deferred because factor specialization was not healthy.
- **Shared-generator/capacity hypothesis:** still plausible after H2, H3, and functional-loss insufficiency. The existing factor-generator specialization implementation was audited and used unchanged; it adds factor IDs plus four existing per-factor output heads before text encoding while leaving CLIP, adapters, Router, ACT, rho, and factor loss unchanged.

## Why factor-generator specialization was tried

The surviving hypothesis was that excessive shared generation compressed factor identities/functions into a common solution. The source audit found and reused the existing opt-in implementation (`factor_generator_specialization_enabled`), rather than inventing another head family. It inserts factor IDs and `factor_output_heads` after shared `state_to_context` and before text encoding.

The exact latest config delta from the validated functional-specialization fresh 3e was only:

```text
h6_factor_generator_specialization_enabled: false -> true
save_path: functional_specialization_fresh_3e_seed0 -> factor_generator_specialization_fresh_3e_seed0
```

The source audit reports added capacity `2,556,928` parameters: factor ID embedding `1,024`, factor ID-to-context `196,608`, and four output heads of `589,824` each. H6 parameters changed from `7,106,054` to `9,662,982` (relative increase `0.3598238910`). CLIP, image adapter, text adapter, Router, ACT, rho, and factor loss were unchanged.

The zero-step causal proof is `runs/p1_v84a_gpu/specialization_root_cause/factor_generator_zero_step_proof.json` and passed. On the fixed 12-sample cache / 44,046 valid group-patches, effective rank improved `1.3320405 → 2.0984173`, top-1 energy `0.9177803 → 0.7618729`, top-2 `0.9996265 → 0.9302152`, and maximum off-diagonal absolute correlation `0.9995011 → 0.7259337`. Factor-specific gradients were distinct and all invariants were exact; no optimizer, backward, or state mutation occurred.
